SWYNEX – AI Problem Design

Project Title

AI-Based Smart Tourism Question Classification System

1. Problem Statement

Tourists often ask questions about tourist attractions, travel routes, accommodation, weather, and safety. Finding the correct information can take time.

The proposed AI system will automatically classify tourist questions into relevant categories to help organize tourism information and improve the travel experience.

2. Target Users

- Local and international tourists
- Travelers
- Tourism service providers
- Travel planners

3. Data Source

A small, self-created dataset containing approximately 50 sample tourism-related questions.

Each question will be assigned one of five categories:

1. Attractions
2. Routes
3. Accommodation
4. Weather
5. Safety

4. AI Approach

The proposed system will use a text classification approach to identify the category of a tourist's question.

A simple machine learning or NLP model can be used in future implementation.

5. Constraints

- Small dataset (approximately 50 questions).
- English-language questions only in the initial version.
- Limited training data.
- No personal or sensitive user information.
- The initial system will focus only on question classification, not complete travel planning.

6. Success Criteria

The project will be evaluated using:

- Classification accuracy
- Precision
- Recall
- F1-score

Target: Achieve at least 80% classification accuracy on a separate test dataset.

7. Expected Outcome

A basic AI-based tourism question classification system that can organize tourist queries into five meaningful categories.

8. Future Improvements

- Support Urdu and other local languages.
- Add tourist destination recommendations.
- Provide route and estimated travel cost information.
- Integrate an AI tourism chatbot.

Conclusion

This project aims to use Artificial Intelligence and Natural Language Processing to make tourism information more organized and accessible for travelers.# SWNEX-AI-Problem-Design
